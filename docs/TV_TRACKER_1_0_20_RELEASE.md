# Tv Tracker 1.0.20

Released November 11, 2026.

- Adds Revert Excel with durable backups, exact workbook restoration, and protection against overwriting later manual edits.
- Protects existing Completed and Delivered and Need to Assign Excel orders from automatic status updates.
- Limits Production Report status changes to eligible moved orders with statuses shared by the selected SLA Status report.
- Adds order-number search and staged status editing with pencil, confirm, cancel, and custom-status controls.
- Corrects SLA date-only and expiration date/time formats, and marks Search In Progress additions as New Orders.
- Routes Home Builder Update orders to the C-O and Update report.
- Preserves assignment-pending labels in SLA Compare and includes Unknown SLA in summary totals and downloads.
- Fixes Clear Report persistence and adds an explicit Sheet_sync switch for manual Sheets synchronization.
- Refreshes Production Report forms, KPI cards, table grid lines, popup sizing, dropdown visibility, and highlighted success and warning notifications.

Local captures and encrypted connections are retained. The Windows installer follows the existing unsigned distribution process; Windows may show an unknown-publisher warning.
