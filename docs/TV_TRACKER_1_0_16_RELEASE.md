# Tv Tracker 1.0.16

- Drag and drop one or more Excel or CSV production reports anywhere in SLA Compare, with file validation and upload feedback.
- Open the configured Google Sheet from the shared Google Sheet link in every workspace section.
- Show Daily Orders and Monthly Orders only in Import Excel report mode; Tracker report mode explains where to view these reports.
- Keep Google Sheets Monthly Orders and Daily Status Report tabs free of summary results. Imported reports and downloads remain available in the app.
- Replace All Products with the latest saved queue preview rather than accumulated history; preserve capture history separately.
- Automatically compare the selected queue preview against imported production workbooks, refreshing Google Sheets edits first and showing a warning when saved data is used offline.
- Keep latest-preview rows separate from imported-workbook edit reconciliation.

Local captures and saved connections are retained. This Windows release follows the existing unsigned installer distribution process.
