# Tv Tracker 1.0.13

Released October 30, 2026.

- Home Builder products, including Home Builder Lot Out-Sale and the portal label Home Builder L.., appear under Home Builders in SLA Status, order details, Sheets reports and Excel exports. Saved Home Builder labels resolve to the same group.
- Typing in Progress requires Task Name TypingModule with Task Status In Progress or Task Suspended. Task Suspended on another task no longer automatically becomes Typing in Progress. Higher-priority queue rules and manual edits remain supported.
- The built interface includes the SLA preview selector. SLA Status uses its selected preview independently of the capture selected in the sidebar; choose a preview containing the desired orders.

Local captures and encrypted connections are retained. Existing previews retain their original captured fields.

The Windows installer follows the existing unsigned release process. Windows may show an unknown-publisher warning.
