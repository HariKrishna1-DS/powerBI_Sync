# Tv Tracker 1.0.22

Released November 13, 2026.

- Adds a labeled Add status button beside Download Summary in the SLA Compare summary matrix. Newly saved statuses start with zero orders and remain available for order additions.
- Includes saved custom status rows in the summary Excel download without increasing order totals.
- Adds shared status selection with existing choices and custom typing. Limits the field width and dropdown height, and makes status-name dialogs compact.
- Adds comparison status editing, order details, copy and add actions using the selected SLA preview and its revision checks.
- Keeps full order comments readable in the editor and refines the workspace context layout.

Local captures and encrypted connections are retained. The Windows installer follows the existing unsigned distribution process; Windows may show an unknown-publisher warning.
