# Tv Tracker 1.0.18

Released November 10, 2026.

- Refreshes SLA Status and SLA Compare with larger, consistent fonts and clearer cards, tables, and controls.
- Opens both SLA reports at their report controls or cards by default.
- Enlarges order detail dialogs and contains search results within the page.
- Centers the report source switch and compacts the bottom-right activity button.
- Removes the add-order icon from individual row actions.
- Adds Copy New Orders for Excel in production worksheet column order.
- Keeps the preview status when a matched imported Excel order is Completed and Delivered.

Local captures and encrypted connections are retained. The Windows installer follows the existing unsigned distribution process; Windows may show an unknown-publisher warning.
